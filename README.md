# Local Plan

Local Plan is a local-first desktop task and note planner.

## What it does

- Add a task manually.
- Add optional subtask notes under a task.
- Edit task text and subtask notes after creating it.
- Move a task or note to trash immediately, with a six-second undo action.
- Drag each task's progress slider from 0% to 100%.
- Task cards change color as progress increases.
- Progress never marks a task done by itself; use the task button to complete it.
- Click a task button to mark it done.
- Restore a completed task if needed.
- Move all completed tasks to trash together, with a single undo action.
- Search tasks and notes from one search field while keeping the query between views.
- Add, edit, pin, and delete notes; note titles are optional and unfinished drafts are restored.
- Attach photos or screenshots to tasks and notes by dragging image files into the input area or pasting them directly; thumbnails appear automatically, with up to three images per item and a 1 MB limit per image.
- Move deleted tasks and notes to a shared trash, then restore or permanently delete them.
- Export all tasks, notes, and trash as a versioned JSON backup through the native Windows save dialog.
- Preview and import a validated JSON backup through the native Windows open dialog.
- Automatically back up local data each day and retain the latest seven backups.
- Optionally remove items that have remained in trash for more than 30 days.
- Keep tasks and notes locally in the app storage.
- Press `Ctrl + Alt + Space` to show the app while it is running.
- Press `Ctrl + F` to focus search and `Ctrl + N` to focus the current add form.
- Press `Enter` to add from a task details or note content field; use `Shift + Enter` for a line break.
- Press `Esc` to clear focused search, cancel editing, or close an open menu or import preview.
- Use the floating `LP` button to open the app, drag it around the screen, and release to snap it to the nearest screen edge.
- Show or hide the floating `LP` button from the main window.

No categories, no reminders, no due dates, no preset tasks.
